# Data Sources

This project uses official Arabic legal and regulatory texts
published by SDAIA.

## Core Documents
1. Personal Data Protection Law (PDPL)
2. Implementing Regulation
3. Personal Data Transfer Regulation

## Additional Documents
1. Data Sharing Policy
2. Data Monetization Policy
3. Appointing Personal Data Protection Officer
4. Accreditation Certificates
5. Accreditation Licensing
6. Secondary Use of Data

## Data Processing
Run the notebooks in the notebooks/ folder to extract
and preprocess the official documents.

Generated datasets are stored locally and are not
committed to this repository.
