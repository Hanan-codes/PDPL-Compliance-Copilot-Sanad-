# Evaluation

This folder contains the evaluation datasets and scripts
for the PDPL Compliance Copilot (Track B).

## Evaluation Components

- Gold Q&A dataset (at least 60 questions)
- At least 20 Arabic questions
- At least 10 unanswerable questions
- Gold article references and reference answers
- Retrieval and answer evaluation
- Privacy policy gap analysis evaluation

Evaluation datasets are being prepared.
