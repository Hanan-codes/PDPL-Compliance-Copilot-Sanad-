# سَنَد / SANAD — مساعد الامتثال لنظام حماية البيانات الشخصية (PDPL)
### "امتثالٌ بدليل"
مشروع تخرّج — برنامج AIEP، المسار B

---

## الفكرة
**سَنَد** مساعد ذكي يجيب عن نظام حماية البيانات الشخصية السعودي ولائحته التنفيذية
بإجاباتٍ **مؤسَّسة على النص الرسمي ومُستشهَد بها**، ويحلّل سياسة خصوصية أي جهة
ليكشف فجوات امتثالها (مُغطّى / جزئي / مفقود). هدفنا أداة عملية تقلّل زمن المراجعة
القانونية وتمنع الهلوسة بربط كل إجابة بمادّتها.

## المشكلة
متطلبات حماية البيانات في المملكة **موزّعة على أكثر من جهة تنظيمية** — سدايا
(الجهة المرجعية لنظام PDPL ولائحته)، ووزارة الموارد البشرية (بيانات الموظفين)،
وجهات قطاعية أخرى — ولكلٍّ نصوصها، **بلغتين (عربي وإنجليزي)**. فالجهة التي تريد
الامتثال مضطرّة للتوفيق بين مصادر متفرّقة. مراجعة ذلك يدويًّا بطيئة وتحتاج خبرة
قانونية وعُرضة للخطأ، ونماذج اللغة العامة تُجيب بثقة دون دليل وقد تهلوس. سَنَد يحلّ
ذلك بـ: توحيد الاسترجاع **عبر اللغتين** (عربي↔إنجليزي)، والتأسيس على النصوص الرسمية،
والتحقق من الاستشهاد، والامتناع عند غياب الأساس.

## المكوّنات
1. **نظام الاسترجاع المعزّز (RAG) —** تقطيع على مستوى المادة، استرجاع هجين
   (BM25 + تضمين متعدد اللغات + إعادة ترتيب)، ثم توليد مؤسَّس **مع تحقّق استشهاد
   وامتناع** عند غياب الأساس. (`rag_inference.py`)
2. **مُصنّف البنود —** يصنّف بنود سياسة الخصوصية إلى فئات (مبني على OPP-115).
   (`clause_classifier_inference.py` + `e4_tfidf_lr_model.joblib`)
3. **محلّل الفجوات —** يقابل 23 متطلبًا من النظام واللائحة بنص الجهة ويُصدر تقريرًا
   بأدلّة من الطرفين. (`gap_analyser.py` + `gap_analyser_inference.py` + `pdpl_requirements_checklist.json`)

## الواجهة
واجهة **Streamlit** بهوية سَنَد، ثلاثة تبويبات: سؤال/جواب، تحليل امتثال، تعريف.
المزوّدات المدعومة: **Ollama (محلي) و Gemini (سحابي)**.

## التشغيل
```bash
pip install -r requirements.txt
export STAGE_DATA_DIR=./data      # مخرجات المرحلتين 1 و2 (الفهارس والمقاطع)
streamlit run app.py
```
ثم من الشريط الجانبي: اختاري المزوّد ومجلد البيانات، واضغطي **«الاتصال / تهيئة النظام»**.
- **Ollama:** `ollama serve` ثم `ollama pull qwen2.5:7b`.
- **Gemini:** الصقي مفتاح API في الشريط الجانبي (يُحفظ بالجلسة فقط).

## الملفات

## تنبيهات
- **سَنَد ليس استشارة قانونية** — أداة مساعدة، وكل إجابة مؤسَّسة على مادة رسمية مُستشهَد بها.
- تقييم المحلّل تمّ على 10 سياسات سعودية حقيقية بتعليمٍ يراجعه الفريق قبل الاعتماد.
- السياسات العربية تحتاج ترجمة قبل التصنيف (المُصنّف إنجليزي) — حدٌّ موثّق.
